# 📚 StudyBuddy

StudyBuddy is a collaborative learning web application designed to help students organize study sessions, share resources, track deadlines, and improve academic productivity.

## ✨ Features

* **Task & Deadline Management:** Keep track of assignments, exams, and daily study goals.
* **Resource Sharing:** Upload and share notes or reference materials with your peers.
* **Progress Tracking:** Visualize study streaks and completed tasks.
* **Responsive UI:** Fully optimized for both desktop and mobile browsers.

## 🛠 Tech Stack

* **Frontend:** React.js, React Router
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Styling:** CSS3 / Tailwind CSS 

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/studybuddy.git

```

2. **Navigate to the frontend directory:**
```bash
cd studybuddy/frontend

```


3. **Install dependencies:**
```bash
npm install

```



## 📜 Available Scripts

In the project directory, you can run:

### `npm start`

Runs the app in development mode.
Open [http://localhost:3000](http://localhost:3000) to view it in your browser. The page will reload when you make changes.

### `npm test`

Launches the test runner in interactive watch mode.

### `npm run build`

Builds the app for production to the `build` folder. It correctly bundles React in production mode and optimizes the build for the best performance.
